# tg-focus — только важное в Telegram

Плагин [Agents Hub](https://github.com/flagman/agents-hub-core): бот Telegram шлёт владельцу итоги и вопросы, а не каждую
передачу работы между сессиями, и раз в N минут — одну сводку его открытых задач.

- **Тишина передач.** Сессия передала работу дальше (задача другой сессии, сообщение ей, `--fyi`) — её промежуточный
  итог бот придерживает. Пришёл итог по задаче или ответ на ваше сообщение — придержанное выкидывается. Цепочка кончилась
  без итога — придержанное уходит одним сообщением. Признак передачи — факты ядра, не текст. Включается при первом
  запуске плагина (`telegram.focus` в `hub.json`); выключили — плагин его не трогает.
- **Сводка задач.** Раз в 30 минут (`telegram.digest_minutes`, 5–1440) — одно сообщение: ваши открытые задачи, у каждой
  — что за задача, кто делает и что с ней: ждёт вас, стоит N мин (ядро напоминает или решает хаб), работает, работают
  исполнители, сессия спит. Новая сводка стирает прежнюю; открытых нет — прежняя стирается, новая не приходит. Только
  задачи, которые поставили вы; подзадачи исполнителей и задачи сессий друг другу — нет. Выключатель —
  `telegram.digest`. Сводка — по этому хабу: задачи другого хаба на другой машине в ней не видны.
- **Настройки** — «Настройки → Только важное».

Нужен хаб с опцией бота `telegram.focus` и фактом `telegram.digest {key, text}`.
